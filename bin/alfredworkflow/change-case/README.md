# Change Case Alfred Workflow

Pure Ruby Alfred rewrite of Raycast's Change Case extension.

- `case text` transforms typed text.
- `case` transforms clipboard text.
- Universal Action transforms selected text.
- Configure the included hotkey if desired.
- Return copies to clipboard.
- Command-Return pastes to the frontmost app.
- Option-Return pins or unpins a case.

No npm packages, gems, or Alfred workflow libraries are required.
