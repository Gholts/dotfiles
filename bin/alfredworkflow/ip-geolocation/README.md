# IP Geolocation Alfred Workflow

Alfred rewrite of Raycast IP Geolocation.

## Usage

- `ipgeo example.com`: query IP or domain geolocation.
- `myip`: show local/public IP and public geolocation.
- `copyip`: copy local/public IPv4/IPv6.

Press `Enter` to copy selected row. Press `Command-Enter` to copy all info when available.

Configuration supports language, coordinate order, IPv6 display, and keywords.

Source behavior based on:
https://github.com/raycast/extensions/tree/870667fc671801a467deb7c4c7fc72992efe3820/extensions/ip-geolocation
