# Image Search

Reverse image search with Google Lens or Yandex Images.

## Keywords

- `lens [image URL or local path]` searches Google Lens.
- `yimg [image URL or local path]` searches Yandex Images.
- Run either keyword without an argument to select a screenshot area.

Both keywords are configurable in workflow settings.

## Universal Actions

Select one image file, open Alfred Universal Actions, then choose:

- `Search Google Lens`
- `Search Yandex Images`

Google opens a one-shot local upload page in the macOS default browser so browser cookies and image data stay in one session. Yandex uploads directly and opens its result URL. No clipboard paste or Accessibility permission is required.
